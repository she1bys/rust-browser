Performance

Memory saver
Efficiency mode

Never put to sleep: the tab you're looking at, tabs playing sound, tabs with a download running, and private tabs. Hover over a tab to see how much memory it uses.

Privacy

Clear browsing data
Deletes cookies, cache and site data. You will be signed out of most websites.
Clear browsing history
Removes all visited pages from your history list.
Block pop-ups
Stops pages from opening windows you didn't click for. You can still open a blocked one.
Block ads and trackers
Pages load faster and use less memory. If a site doesn't work right, turn this off and reload it.
Tracking prevention
Blocks trackers that follow you from site to site. Strict may break some sites.
Offer to save passwords
Remembers passwords you type into sign-in forms, on this PC only.
Autofill forms
Suggests addresses and other details you've entered before.
Protect me from dangerous sites
Microsoft Defender SmartScreen warns you before phishing and malware sites, and dangerous downloads.

Private tabs (Ctrl+Shift+N) keep no history, cookies or saved tabs after the browser closes.

Import

Bring in bookmarks and history
Copies them from another browser on this PC. Nothing in that browser changes.
Import a bookmarks file
An .html file exported by Firefox, Safari, Opera or any other browser.

Saved passwords can't be imported: the web engine Rust Browser uses has no way to add them. In the other browser, open its password settings to look them up, and Rust Browser offers to save each one the next time you sign in.
